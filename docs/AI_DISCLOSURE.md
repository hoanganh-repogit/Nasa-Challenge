# AI disclosure

## Tools

- **Claude Code** with **Claude Opus 5.5** (Anthropic), used throughout the build as a coding and writing assistant.
- Claude Code skills: `impeccable` (design direction, critique, audit, DESIGN.md) and `teardown` (frame-by-frame
  capture tooling and the procedural sound kit). Playwright and axe-core were used for testing.

## What AI helped with

- **Code:** the Python ETL, the replay engine and its tests, the three.js stage, the light-paint reveal, the React
  interface, the /rover, /about and /film pages, and the capture and checking scripts.
- **Writing:** drafting the stop questions, leads, cards, FAQ, part captions and Legacy rows, always from NASA, JPL or
  NSSDCA pages that were opened and quoted first. A content lint and a source checker run on every change.
- **Research support:** fetching NASA pages and copying exact sentences, so quotes could be checked word for word.
- **Design:** the "Night Exposure" visual direction was chosen by the author from rendered options; AI helped build
  and review it (contrast, accessibility, layout on phones).
- **The film score** is synthesised by code, not generated by a music model.
- **The film's English voice-over is a synthetic voice.** It was generated on the author's laptop with Kokoro-82M
  (open-weight text-to-speech, Apache-2.0, voice `af_heart`) by `film/narrate.py`. The narration script (about 75
  words) was written with AI help from the site's sourced content. The captions are the same words, timed to the voice.

## What AI did not do

- It did not produce data. Every rover position comes from the traverse table; every image is a NASA image with its
  credit; every fact links to a NASA, JPL or NSSDCA page.
- No AI-generated images or 3D models are used. The rover is NASA's own model. The only AI-generated media is the
  synthetic narration voice in the film, disclosed above.
- The site has no chatbot or AI-written answers at runtime.

## Human decisions

The author chose the challenge, the rover, the story, the visual direction and every scope decision (for example,
Mars only), reviewed the work at each stage, and is responsible for the result. NASA has not reviewed or endorsed it.

## Space Apps SI rules: where the indicators are

Space Apps 2026 calls these tools Super Intelligence (SI) and asks for visible or written indicators. Here they are:

| Element | SI use | Indicator |
|---|---|---|
| Film (video) | Pictures rendered by the project's own code (written with SI help); voice-over SI-generated | Visible watermark in the top-left corner for the whole film: "SI-generated voice-over · SI-assisted code"; the same line on /film |
| Film audio | Voice-over SI-generated (Kokoro-82M); music synthesised by code | This page, /about, CREDITS.md, the YouTube description, and the `comment` metadata of the mp4 and m4a files |
| Code | Written with SI assistance (Claude Code) | This page, the README, `package.json` description, the `ai-disclosure` meta tag in `index.html` |
| Text | Drafted with SI assistance from NASA, JPL and NSSDCA sources | This page and /about |
| Images, 3D model, data | No SI generation: NASA images, NASA's model, NASA's traverse table | Credits on every image; CREDITS.md |

No NASA logo, flag, insignia or mission patch is used, by SI or otherwise.
